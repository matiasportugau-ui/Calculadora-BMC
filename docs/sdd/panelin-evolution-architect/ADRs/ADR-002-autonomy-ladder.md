# ADR-002: Autonomy ladder with durable grants

**Status**: Accepted  
**Context**: All levels (investigate → PR → merge) desired; never autonomous unless explicitly asked/defined.  
**Decision**: Default max L2; L3–L5 require `pea.grants`; L4/L5 not chat-metadata-only.  
**Consequences**: + Safety; − Explicit escalation friction.  
**Alternatives considered**: Always auto-PR; recommend-only forever.
