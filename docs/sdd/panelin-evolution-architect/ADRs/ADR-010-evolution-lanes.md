# ADR-010: Multi-lane evolution (A′) — H / K / C

**Status**: Accepted  
**Date**: 2026-08-09 (Module 0 Q&A — user chose option 1 / A′)  
**Context**: Uncertainty that PEA should always act as a coding brain; industry systems evolve harness/knowledge first.  
**Decision**: Two runtimes (Panelin + PEA). Three lanes with preference **H harness → K knowledge (PAOS) → C code**.  
**Consequences**: + Right-sized fixes; − Lane misroute (mitigate Critic + path allowlists).  
**Alternatives considered**: Code-only PEA (A); mega-agent (B); Issue-only (C); Kitchen-first (E).
