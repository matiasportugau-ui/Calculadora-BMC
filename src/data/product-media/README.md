# Product media catalog

Central Shopify product media for calculator (step 8 accessories + Agregar producto).

| File | Role |
|------|------|
| `product-media-catalog.json` | Storefront snapshot (73 products) |
| `product-media-links.json` | Curated calc key → handle/image |
| `productMediaResolve.js` | Runtime API |
| `calcMediaKeys.js` | Mapper key list |

```bash
npm run catalog:media:sync
```

Mapper UI: `/preview/product-media-mapper`
