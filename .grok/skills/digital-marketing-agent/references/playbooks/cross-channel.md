# Playbook — Cross-channel digital marketing

Run after Meta and/or Google and SEO pulls when mode is full/weekly or user asks budget mix / funnel.

## Synthesis questions

1. **Budget mix** — Share of spend Meta vs Google vs other; which channel owns efficient volume?
2. **Message consistency** — Same offer, price framing, CTA across ads and organic?
3. **Funnel handoff** — Ads → landing → quote (calculadora / WhatsApp / ML / Shopify). Where drop-off is implied?
4. **Audience/query wars** — Same audience or keywords fighting each other?
5. **Creative learning transfer** — Winning Meta hooks → Google RSA/PMax assets and vice versa.
6. **Tracking unity** — Same conversion definition across platforms?

## BMC funnel context

| Stage | Surface |
|-------|---------|
| Discovery | Meta, Google, SEO, ML, Shopify |
| Consideration | Site, calculadora, PDF quote |
| Conversion | Cotización / order / WA |
| Ops | Admin sheet, CRM, Hub |

Recommendations should name the stage and the lever (media, creative, landing, tracking, offer).

## Output

Section 5.4 + cross rows in backlog. Prefer reallocations and tests over “spend more everywhere”.
